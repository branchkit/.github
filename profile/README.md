# BranchKit

Local push-to-talk dictation and voice control for macOS.

Hold Option+T, speak, release — text appears at the cursor. Voice commands control windows, apps, browser, and more. Runs entirely on-device.

## For Plugin Developers

- **[plugin-sdk-go](https://github.com/branchkit/plugin-sdk-go)** — Go SDK for building plugins
- **[bridge](https://github.com/branchkit/bridge)** — Wrap any HTTP server as a BranchKit plugin (any language)
- **[docs](https://github.com/branchkit/docs)** — Developer documentation
